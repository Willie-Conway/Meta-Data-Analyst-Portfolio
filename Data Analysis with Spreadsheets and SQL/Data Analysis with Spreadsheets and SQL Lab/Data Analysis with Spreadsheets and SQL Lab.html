Common Data Cleaning Tasks:
• Remove Duplicates: =UNIQUE(range) or Data → Data cleanup → Remove duplicates
• Trim Whitespace: =TRIM(cell)
• Standardize Dates: =DATEVALUE(cell) or Format → Number → Date
• Handle Missing Values: =IF(ISBLANK(cell), "Unknown", cell)
• Format Currency: Format → Number → Currency
• Standardize Text: =UPPER(cell), =LOWER(cell), or =PROPER(cell)
🧮 Spreadsheet Functions Explorer

Explore common spreadsheet functions for data analysis. Enter numbers to see calculations.

SUM Function
=SUM(A1:A10)
Adds all numbers in a range of cells. Essential for calculating totals.
AVERAGE Function
=AVERAGE(A1:A10)
Calculates the arithmetic mean of numbers in a range. Great for finding central tendency.
COUNT Function
=COUNT(A1:A10)
Counts the number of cells that contain numbers. Useful for data validation.
VLOOKUP Function
=VLOOKUP(value, range, column, FALSE)
Searches for a value in the first column of a range and returns a value in the same row from a specified column.

SELECT Statement Syntax:
SELECT column1, column2, ...
FROM table_name
WHERE condition
ORDER BY column1 [ASC|DESC]
LIMIT number;
• Use * to select all columns
• Use AS to rename columns (aliases)
• Use DISTINCT to get unique values
• Use TOP or LIMIT to restrict results
🔍 WHERE Clause Practice

Filter data using WHERE clauses with conditions and logical operators.

SELECT * FROM orders WHERE total_amount > 100;
SELECT * FROM customers WHERE city = 'New York' AND status = 'Active';
SELECT * FROM products WHERE category IN ('Electronics', 'Books');
WHERE Clause Operators:
• = : Equal to
• != or <> : Not equal to
• > : Greater than
• < : Less than
• >= : Greater than or equal to
• <= : Less than or equal to
• IN : Match any value in a list
• LIKE : Pattern matching with wildcards
• BETWEEN : Between a range of values
• IS NULL : Check for null values
📈 Aggregate Functions Practice

Use aggregate functions to calculate summary statistics from your data.

SELECT COUNT(*) AS total_orders, SUM(total_amount) AS total_revenue, AVG(total_amount) AS avg_order_value, MIN(total_amount) AS min_order, MAX(total_amount) AS max_order FROM orders;
Aggregate Function Notes:
• COUNT(*) counts all rows including NULLs
• COUNT(column) counts non-NULL values only
• SUM ignores NULL values
• AVG calculates (SUM/COUNT) ignoring NULLs
• MIN/MAX work with numbers, dates, and text
• Use DISTINCT with aggregates for unique values
👥 GROUP BY Practice

Group data by categories and calculate aggregates for each group.

SELECT category, COUNT(*) AS product_count, AVG(price) AS avg_price, SUM(quantity) AS total_quantity FROM products GROUP BY category ORDER BY product_count DESC;
GROUP BY Rules:
1. All columns in SELECT must either be in GROUP BY or be aggregate functions
2. GROUP BY comes after WHERE and before ORDER BY
3. Use HAVING to filter groups (like WHERE for individual rows)
4. You can GROUP BY multiple columns
5. NULL values form their own group
6. Use ROLLUP or CUBE for subtotals

Data Visualization

Learn to create effective visualizations to communicate data insights.

📊 Bar Chart Creator

Create bar charts to compare categories or show frequency distributions.

When to Use Bar Charts:
• Comparing categories or groups
• Showing changes over time (when categories are time periods)
• Displaying frequency distributions
• Comparing parts to a whole (stacked bar charts)
• Showing rankings or ordered categories

Best Practices:
• Order bars logically (alphabetically, by value, or chronologically)
• Use consistent colors for the same categories
• Include data labels for clarity
• Start y-axis at zero to avoid misleading comparisons
📈 Line Chart Creator

Create line charts to show trends and changes over time.

When to Use Line Charts:
• Showing trends over continuous time periods
• Comparing multiple trends on the same chart
• Displaying rates of change
• Showing cumulative totals (area charts)
• Forecasting future trends

Best Practices:
• Use consistent time intervals
• Clearly label time periods
• Use different line styles for multiple series
• Consider using markers for data points
• Use gridlines sparingly for readability
⚫ Scatter Plot Creator

Create scatter plots to explore relationships between two variables.

When to Use Scatter Plots:
• Exploring relationships between two continuous variables
• Identifying correlations (positive, negative, or none)
• Detecting outliers or anomalies
• Showing clusters or groupings in data
• Visualizing the strength of relationships
• Comparing distributions across categories

Best Practices:
• Add trend lines to show relationships
• Use color or size to represent a third variable
• Include correlation coefficient if applicable
• Label outliers for investigation
• Consider log scales for wide-ranging data
🥧 Pie Chart Creator

Create pie charts to show proportions and percentages of a whole.

When to Use Pie Charts:
• Showing proportions of a whole (parts-to-whole relationships)
• When you have 2-5 categories (avoid too many slices)
• Comparing relative sizes of categories
• Simple percentage breakdowns
• When exact values are less important than proportions

Best Practices:
• Limit to 5-7 slices maximum
• Order slices from largest to smallest
• Use contrasting colors for different slices
• Consider using a donut chart for a cleaner look
• Include percentages and labels for clarity
• Consider bar charts as an alternative for precise comparisons
