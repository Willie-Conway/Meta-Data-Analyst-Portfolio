Formal Hypothesis Statements

Statistical formulation for testing

Null Hypothesis (H₀): μ_facebook = μ_adwords
"There is no difference in mean conversions between Facebook and AdWords"

Alternative Hypothesis (H₁): μ_facebook > μ_adwords
"Facebook has significantly higher mean conversions than AdWords"

This is a one-tailed test because we're specifically testing if Facebook is better
🎯 Why This Hypothesis?

1. Business Context: Need to allocate budget effectively between platforms

2. Data Driven: Preliminary analysis shows Facebook mean = 11.36, AdWords mean = 6.13

3. Statistical Approach: One-tailed t-test appropriate for directional hypothesis

4. Actionable Outcome: Clear decision for budget allocation

Final Model Selection: Simple Linear Regression

Regression Equation Form:
Conversions = β₀ + β₁ × Clicks + ε
Where:
β₀ = Intercept (conversions at 0 clicks)
β₁ = Slope (conversions per click)
ε = Error term

Linear regression answers: "Conversions = a + b × Clicks"

This direct alignment makes simple linear regression the ideal choice for our predictive modeling needs.

Formal Hypothesis Statements

Statistical formulation for testing

Null Hypothesis (H₀): μ_facebook = μ_adwords
"There is no difference in mean conversions between Facebook and AdWords"

Alternative Hypothesis (H₁): μ_facebook > μ_adwords
"Facebook has significantly higher mean conversions than AdWords"

This is a one-tailed test because we're specifically testing if Facebook is better
🎯 Why This Hypothesis?

1. Business Context: Need to allocate budget effectively between platforms

2. Data Driven: Preliminary analysis shows Facebook mean = 11.36, AdWords mean = 6.13

3. Statistical Approach: One-tailed t-test appropriate for directional hypothesis

4. Actionable Outcome: Clear decision for budget allocation
